Şu sıralar uğraştıklarım:

- [saysay-ai](https://github.com/atss0/saysay-ai) – fotoğraftan mercimek ve pirinç tanelerini sayan küçük bir masaüstü uygulaması.

Kullandıklarım: React, React Native, Next.js, Laravel, Unity, PostgreSQL, Redis, Docker.
